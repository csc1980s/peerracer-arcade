## 🚀 ArtCraft Integration

### Automation Workflow

The decks are designed to be generated using **ArtCraft PhotoCraft** automation:

```bash
# Quick Start
cd solitaire
chmod +x card_deck_quick_start.sh
./card_deck_quick_start.sh

# Interactive menu will guide you through:
# 1. Select a deck theme
# 2. Automatic generation of all 54 cards
# 3. Export to print and digital formats
```

### Generation Process

1. **Setup Workspace** → Creates directory structure
2. **Load Templates** → PSD files with layer organization
3. **Apply Theme** → Colors, textures, artwork per deck
4. **Generate Cards** → Automated batch processing
5. **Export Formats** → PNG (digital), PDF (print)

**Time per deck:** ~2 hours for complete 54-card generation

## 📊 Specifications

### Card Dimensions
- **Poker Size:** 2.5" × 3.5" (63.5mm × 88.9mm)

- **Web:** .jpg (optimized)

- **Print:** CMYK, coated paper
- **Digital:** sRGB color space
- **Special Effects:** Metallic gold, embossing notes

### To Generate Decks

1. **Install ArtCraft PhotoCraft**
   ```bash
   # Follow installation from Artcraft AI Interface Plan.txt
   cargo build --release -p photocraft-cli
   ```

2. **Run Quick Start Script**
   ```bash
   chmod +x card_deck_quick_start.sh
   ./card_deck_quick_start.sh
   ```

3. **Select Theme**
   - Choose from interactive menu
   - Automatic generation begins

4. **Customize (Optional)**
   - Edit PSD templates in PhotoCraft
   - Adjust colors, add personal touches
   - Re-run automation

1. **Copy Output Files**

   - Update UI deck selector
   - Test card loading
